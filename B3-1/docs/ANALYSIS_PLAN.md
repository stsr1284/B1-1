# B3-1 OD 분석 실행 계획

## 목표와 질문

**2023~2025년 및 2026년 비교 가능 기간의 대중교통 이동을 비교해, 서울 지역별 주말·낮·저녁 방문 변화의 단서를 찾는다.** 관광객 수나 방문 목적을 직접 측정한다고 주장하지 않는다.

1. 서울 내 지역 간 이동량은 장기적으로 어떻게 변했고 계절·요일별 패턴은 어떠한가?
2. 명동·서교동·성수2가3동·한남동의 주말 낮/저녁 이동 변화는 평일 아침과 어떻게 다른가?
3. 2026년 1~8월은 전년 같은 기간과 비교해 어떠한가? 범위를 서울 밖 출발지까지 넓혀도 방향이 같은가?

## 과제 원문과 결과물

| 원문 필수 조건 | 구현·검증 |
|---|---|
| 시계열 100개 이상, 출처·기간 | 공식 OD 원본 66ZIP, 관측 날짜 1,366일; 누락일 별도 |
| 질문 3개 이상 | 위 질문 3개 |
| 결측·이상치 처리 | 누락 24일 보간 금지; 빈 시간 셀 미상 유지; 숫자 오류 실패; 코드·중복 감사; 이상일 보존 및 제외 민감도 |
| 분석 기법 2개 이상 | 28일 이동평균, 월×요일 표준화 평균·전년 변화율, 시간대 프로파일 |
| 시각화 2개 이상(3개 권장) | 일별 추세, 월별 추세, 관심 지역 증감, 요일×시간 히트맵 |
| 근거 있는 인사이트 3개 이상 | 실행 수치와 그래프를 연결한 관찰·가설·한계 |
| REPORT.md + Python + GitHub 저장소 | 리포트, od_analysis 패키지, 재실행 방법·수집 코드·소형 분석표. Git 커밋/푸시는 별도 요청 시 진행 |

보너스 대시보드·예측은 이번 필수 완료 범위에 포함하지 않는다.

## 자료와 비교 범위

```text
공식 ZIP(불변) + 공식 행정동 마스터 + 월별 서울 코드표 + 달력
  -> 검증: SHA/CRC/날짜/숫자/빈값/코드/중복
  -> processed/transit_od/months/*.parquet (재생성 가능한 중간 집계)
  -> 지역별·날짜별 표 / 비교표 / 감사 결과
  -> PNG 그래프 + REPORT.md + HTML 미리보기
```

- 주 분석: 공식 마스터와 2023-01~2026-08 월별 코드표에서 이름·코드가 유지되는 서울 417개 동 중, 별칭 충돌이 발견된 고덕1동과 일부 관측일에 기록이 없는 18개 동을 전 기간 제외한 398개 동 사이 이동. 같은 동 내부 이동 제외.
- 보조 분석: 위 목적지에 대한 비어 있지 않은 모든 출발 ID의 관측 이동량. 서울 외 지역과 같은 동 내부 이동을 포함하므로 주 분석과 합산하거나 동일 지표로 해석하지 않는다.
- 교통 OD ID와 월별 행정코드는 다른 체계다. 숫자를 자르거나 붙이지 않는다. 공식 마스터가 명시한 동일 지역명 ID만 연결한다.
- 월별 코드표는 2026-08까지다. 2026-09~10은 최근 관측 탐색으로 분리하고, 전년 정식 비교는 1~8월로 제한한다. 동일 이름·코드는 실제 경계 불변의 증명이 아니다.
- 연간 비교: 공휴일·특별일을 제외하고 동일 월×요일의 일평균을 같은 가중치로 평균한다. 모든 필요한 층이 있고 각 층 관측일 2개 이상일 때만 제시한다.
- 주말 10~22시(10~21시 열)는 여가 단서, 평일 07~10시(07~09시 열)는 출근 비교군. 시간 수가 다르므로 시간당 관측 이동량으로 비교. 12~20시 재계산으로 민감도 확인.
- 시간은 원본 시간대다. 승차/도착 기준 미확정이며 관광·귀가·업무 등을 확정 분류하지 않는다.

## 품질 정책

원본 전체를 파일/일 단위로 처리해 메모리를 제한한다. 원본 전체 압축 해제본은 만들지 않는다. 검증 로그와 중간 집계는 해시를 연결해 재사용한다.

1. 날짜 공백은 NaN, 관측치 0과 구분. 28일 이동평균은 연속 28개 관측일이 있는 창에서만 표시한다.
2. 빈 시간 셀은 미상. 집계는 알려진 숫자의 합이며 해당 지역·시간에 숫자가 하나도 없으면 미상. 분석 시간 구간은 모든 시간 집계가 존재할 때만 합산한다.
3. 숫자 파싱 실패는 즉시 중단. 음수 행은 제외 수 기록. 정확히 같은 중복은 한 번만 유지; 같은 날짜·OD 키인데 값이 다른 행은 모두 제외하고 기록한다.
4. 7/8자리 코드가 같은 지역에 연결되면 다시 중복 검사한다. 코드 미연결·결측은 감사표에 남긴다.
5. 주 분석의 매일·시간별 유입 합계=유출 합계를 검사한다. 독립 CSV 표본 재계산과 회귀 테스트로 코드 검증.
6. 일반일의 같은 연도·월·요일 중앙값 대비 전체 이동량이 0.35배 미만/2.5배 초과 또는 행 수가 0.5배 미만이면 점검 대상. 자동 삭제하지 않고, 포함/제외 결과를 모두 계산한다. 이 기준은 수집 누락을 확정하는 통계 검정이 아니다.
7. 관광 변화·교통 접근성 영향의 인과 결론은 금지. 날씨·행사·배차·도로·매출·자가용·보행 자료는 포함되지 않았다.

## 파일 관리

OD·코드·달력만 `data/raw/`에 둔다. 기존 승하차·역/정류장 원본은 삭제 없이 `tmp/2026-10-27/unused_data/archive/raw/`로 분리한다. 과거 코드는 이번 파이프라인에서 호출하지 않는다. B3-2 및 과제 원문은 변경하지 않는다.
