# B2-1 요구사항 체크리스트

검증 기준일: 2026-10-07 (Asia/Seoul)

[과제문](과제문.md)과 첫 번째 원본 HTML의 모든 요구사항을 기준으로 작성했다. `[x]`는 직접 확인 또는 사용자의 팀원 완료 확인을 근거로 표시하며, `[ ]`는 미검증·범위 제외·선택 항목을 구분해 표시한다. 보너스는 선택 사항이며 필수 완료 기준과 구분한다. 원문 반복 항목도 해당 절에 각각 기록했다.

**현재 적용 결과: 기존 스크린샷과 동일한 기본 데이터·일반 출력으로 복원했다.** 사용자의 “출력이 동일하게 나오도록 수정” 요청을 반영했다. 기존 반영 버전 9530fc1과 실제 CLI 18개 시나리오의 stdout이 완전히 일치한다. 여러 줄 입력·취소·숫자 검증·검색 등 유지한 기능의 실제 CLI 10개와 함수 직접 검사도 통과했다.

**과제 확인 범위:** 메뉴·추가·목록·카테고리·검색·상세·즐겨찾기 기능은 확인했다. 복원한 예시 3개의 “이전 미션 작성” 출처는 미확인이다. 1.png의 기본 데이터·메뉴·추가 출력은 이제 현재 코드와 일치하지만 해당 이미지에는 검색 결과가 없다. 2.png는 사용자가 현재 저장소에서 직접 촬영한 커밋 10개·브랜치·병합 기록이다. 개인 설명 능력과 init/pull/clone·VSCode 계정 연동은 현재 증거로 미확인이다. 별도 실습 제외 지시는 추가 작업 범위에 적용하며 원문의 충족을 대신 인증하지 않는다.

**Git 상태:** 이전 새 작업 커밋 10개와 실제 브랜치·병합·푸시 기록은 유지한다. 출력 복원과 사용자 Git 증빙·검증 문서를 기능 브랜치에서 커밋하고 main에 병합해 제출한다. 기존 이력을 다시 쓰지 않았으며 원격 반영 여부는 최종 Git 상태로 확인한다.

최신 실행 근거: [검증 로그](docs/evidence/검증_로그.md) 마지막의 **기존 화면 출력 복원 검증** 절. Python 3.13.1로 CLI 18개 출력 일치·유지 기능 CLI 10개를 확인했다. 기존 31개 CLI·8개 함수 검사 및 C/U/I는 출력 복원 전의 과거 검증이다.
