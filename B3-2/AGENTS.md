# B3 작업 지침

작업 전 [과제문](과제문.md), [진행계획](진행계획.md)을 읽는다.
공통 규칙은 B3-1의 [코드 컨벤션](../B3-1/docs/CODE_CONVENTIONS.md), [아키텍처](../B3-1/docs/ARCHITECTURE.md), [파일 구조](../B3-1/docs/FILE_STRUCTURE.md), [협업 규칙](../B3-1/docs/COLLABORATION.md)에 따른다.

- 사용자의 최신 지시와 B3-2의 FastAPI·Firestore·GPT·Render·Vercel 필수 조건을 따른다.
- 초기 자료는 B3-1 정제본과 해시·내용이 같은 복사본을 사용한다.
- B3-2의 CRUD는 DB를 변경한다. B3-1 원본·정제본·리포트를 덮어쓰지 않는다.
- 실제 DB·AI·배포 검증과 테스트 대역의 결과를 구분한다.

- 현재 주제는 2025년 따릉이·버스·지하철 이용량이며 기본 키는 (date, mode)다. 용어 설명 원문의 기온 예시는 과거 대화 기록이다.
