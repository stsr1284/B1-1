# 코드 컨벤션

적용: B3-1과 B3-2의 신규 코드. 과제 원문의 기술 조건을 우선한다.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 환경 | 과제 최소 Python 3.10 이상. B3-1은 고정한 NumPy 2.5 지원을 위해 Python 3.12 이상, 검증 환경은 3.13.1. 프로젝트별 venv·버전 고정 |
| 이름 | Python 파일·함수·변수는 snake_case, 클래스는 PascalCase, 상수는 UPPER_SNAKE_CASE |
| 포맷 | UTF-8, LF, Python 들여쓰기 4칸, 줄 길이 100자. Ruff로 포맷·정적 검사 |
| 타입 | 공개 함수의 입력·반환 타입 명시. 필드와 단위가 불분명한 dict 전달 지양 |
| 함수 | 한 함수는 한 책임. 계산과 파일/네트워크 입출력 분리 |
| 경로 | pathlib 사용. 개인 PC 절대 경로 하드코딩 금지. 기본 경로는 프로젝트 위치 기준 |
| 예외 | 경계에서 구체적 예외 처리. 오류를 숨기거나 임의 정상값으로 대체하지 않음 |
| 설명 | 주석·docstring은 목적·단위·판단 이유 중심. 문서는 한국어, 코드 식별자는 영어 |
| JS/CSS | B3-2는 바닐라 JS. 변수·함수는 camelCase, CSS 클래스는 kebab-case |
| 비밀 값 | 환경 변수에서만 읽음. 코드·로그·테스트 자료에 실제 키를 기록하지 않음 |

## 2. 데이터·계산 규칙

```text
raw input -> validate -> typed values -> calculate -> format -> output
                |                         |
                v                         v
           clear error              no early rounding
```

- 날짜는 YYYY-MM-DD, 실제 달력 날짜를 확인한다. 서버 이벤트 시각은 UTC와 시간대를 포함한다.
- 값은 유한한 숫자만 허용한다. 관측값은 0 이상의 정수이며 단위는 건이다. NaN/Infinity를 JSON으로 내보내지 않는다.
- 계산 중에는 반올림하지 않고 화면·리포트 표시 시 적용한다. 없는 값은 null/결측으로 유지한다.
- 입력 DataFrame을 몰래 수정하지 않는다. 정제 함수는 결과와 품질 정보를 명확히 반환한다.
- 7일 이동평균은 수단별 연속 달력 7일에 유효값 7개가 있을 때 계산한다.
- 수단(mode)을 필수 구분한다. 따릉이 대여와 버스·지하철 승차를 합산해 고유 이용자 수나 수송분담률로 표시하지 않는다.
- 일간 차이는 날짜가 하루 차이일 때만 계산한다. 빈 날짜를 건너뛴 값을 하루 변화로 쓰지 않는다.
- 그래프에는 제목·축·단위·기간을 표시하고, 한글 글꼴은 실행 환경에서 확인한다.

## 3. 검사 규칙

```text
edit -> format/lint -> relevant tests -> run -> inspect results
```

- 구현 시 Ruff·pytest를 개발 의존성으로 기록하고 검증한 버전을 고정한다.
- 테스트는 정렬되지 않은 날짜, 누락일, 중복, 비정상 수치, 잘못된 통계 등 실제 위험을 검증한다.
- 테스트 전용 소규모 자료와 제출용 관측자료를 구분한다.
- 문구 수정만으로 불필요한 테스트를 늘리지 않는다. 통과한 검사는 새로운 변경·실패가 있을 때 재실행한다.
- B3-2의 API 응답·오류 구조와 입력 검증은 Pydantic 스키마에 맞춘다.
