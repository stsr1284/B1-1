# B2-1 요구사항 체크리스트

검증 기준일: 2026-10-07 (Asia/Seoul)

[과제문](과제문.md)과 첫 번째 원본 HTML의 모든 요구사항을 기준으로 작성했다. `[x]`는 직접 확인 또는 사용자의 팀원 완료 확인을 근거로 표시하며, `[ ]`는 미검증·범위 제외·선택 항목을 구분해 표시한다. 보너스는 선택 사항이며 필수 완료 기준과 구분한다. 원문 반복 항목도 해당 절에 각각 기록했다.

**현재 적용 결과: 실제 이전 미션 프롬프트 3개를 기본 데이터에 등록했다.** B1-3 워크플로우의 유튜브·인스타그램 프롬프트 2개와 B1-1 시스템 설계 문서 11절의 최종 프롬프트 1개를 사용한다. 각 본문 전체가 원본과 일치하며 현재 코드의 실제 CLI 26개와 직접 검사 6개가 통과했다. 기본 데이터 함수 외의 코드는 유지했다.

**과제 확인 범위:** 메뉴·추가·목록·카테고리·검색·상세·즐겨찾기 기능과 이전 미션 프롬프트 3개의 등록을 확인했다. 1.png를 현재 CLI의 실제 PTY 입력·출력 화면으로 갱신하여 기본 목록·추가·추가 후 목록·검색 결과를 확인했다. 표시된 내용과 실제 PTY 출력의 일치를 확인했다. 2.png는 사용자가 현재 저장소에서 직접 촬영한 커밋 10개·브랜치·병합 기록이다. 개인 설명 능력과 init/pull/clone·VSCode 계정 연동은 현재 증거로 미확인이다. 별도 실습 제외 지시는 추가 작업 범위에 적용하며 원문의 충족을 대신 인증하지 않는다.

**Git 상태:** 기존 새 작업 커밋 10개와 실제 브랜치·병합·푸시 기록은 유지한다. 이전 제출 통합은 8d93d13에 반영했다. 이번 기본 데이터·문서 보정은 로컬에 적용했으며 커밋·푸시는 아직 수행하지 않았다.

최신 실행 근거: [검증 로그](docs/evidence/검증_로그.md)의 **실제 이전 미션 프롬프트 적용 검증** 절. Python 3.13.1로 원문 본문 3개 전체 비교, 실제 CLI 26개 및 직접 검사 6개를 확인했다. 기존 출력 복원·C/U/I는 각 당시 버전의 검증 기록이다.

### 검증을 통해 확인한 범위

- 원본 첨부 HTML의 ck-content 본문 4개에서 체크리스트에 옮긴 요구 문장 103개를 모두 찾았다. 공백·Markdown 표시만 정규화했으며 문장을 변경하지 않았다. 103개는 반복·예시·선택 항목을 포함하므로 필수 완료 개수로 해석하지 않는다.
- 현재 코드의 본문 3개와 원본 전체 문자열·SHA-256이 일치한다. 등록 개수·4개 필드·카테고리·favorite=False·독립 초기화를 확인했다.
- 현재 코드 SHA-256에 연결된 실제 CLI 26개(이전 15개+이번 11개)와 빈 데이터·검색·숫자 직접 검사 6개가 통과했다.
- 코드 변경 커밋 10개가 모두 실제 GitHub main의 이력에 포함됨을 확인했다. 현재 로컬 보정 코드와 원격 코드의 SHA-256은 달라 최신 보정의 업로드 완료를 주장하지 않는다.
