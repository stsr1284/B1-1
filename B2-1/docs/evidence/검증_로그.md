> C/U/I 및 공고도우미 전문 비교는 출력 복원 전의 과거 검사 기록이다. 현재 코드는 마지막의 “기존 화면 출력 복원 검증” 절을 기준으로 확인한다.

검증 기준일: 2026-10-07 (Asia/Seoul)

- 검증 코드 SHA-256: `3a52634b9e650aaeea213db4c453c70aff7bbab91366eb43bc8cd2be71f69b9e`
- 실행 위치: `B2-1`
- 실제 실행 파일: `/opt/homebrew/opt/python@3.13/bin/python3.13`
- 실제 하위 프로세스 버전: `Python 3.13.1`
- 실행 명령: `/opt/homebrew/opt/python@3.13/bin/python3.13 -B main.py` (C19 SIGINT 시나리오에는 출력 버퍼링 방지를 위해 `-u` 추가)
- 재현 명령: `python3.13 -B main.py`. `python3`은 셸에 따라 다른 버전을 가리킬 수 있으므로 3.10 이상인지 먼저 확인한다.
- 하위 프로세스의 실제 표준 출력과 종료 코드를 기록했다. 파이프 입력이므로 입력 문자가 터미널처럼 자동으로 다시 표시되지는 않는다.
- `C` 항목은 실제 CLI 프로세스 실행이다. `U` 항목은 시작 데이터가 항상 3개인 프로그램에서 전체 0건 방어 처리를 확인하려고 함수를 직접 호출한 것이며 CLI 실행과 구분한다.
- 과제 예시는 정답이 아니므로 예시와 같은 기능·데이터 필드를 확인했다. 예시 프롬프트 제목과 현재 기본 데이터가 다르다고 실패로 판정하지 않았다.
