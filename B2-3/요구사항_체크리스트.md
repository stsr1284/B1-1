`[x]`는 코드·파일·실행으로 확인했거나 사용자가 완료를 확인한 팀원 제출 증빙이 있는 항목이다. 각 항목에 근거를 적는다. `[ ]`는 미확인 또는 선택/학습 목표이며, 제출을 위해 남은 작업과 구분한다.

## 1. 미션 소개


> 아이디어는 있는데, 개발자가 없어서 못 만든다? 이제 그런 시대는 끝났습니다.

> 이 미션에서는 AI 코딩 도구를 활용하여 본인만의 웹 서비스를 직접 만들고, 전 세계 누구나 접속할 수 있는 URL로 배포합니다.

> 이전 미션에서 배운 Python과 API 연동 지식을 활용하여, 방문자가 실제로 상호작용할 수 있는 AI 기능을 구현합니다.
> AI가 맞춤 추천을 해주거나, 문의에 자동 응답하거나, 텍스트를 생성하는 기능을 직접 만들어보세요.

> AI가 코드를 대신 작성해주지만, 단순히 "시키는 대로" 하는 것이 아닙니다.
> 웹이 어떻게 구성되는지 이해하고, AI가 만든 코드에서 오류가 발생하면 직접 원인을 파악하고 수정하는 방법을 배웁니다.
> 미션을 마치면 여러분의 손으로 만든 AI 기능이 탑재된 웹 서비스가 실제 URL을 통해 세상에 공개됩니다.

## 8. 결과 예시

아래는 과제 원문의 참고 예시다. Levelly는 반려동물 서비스 “멍냥케어”와 다른 영어 학습 서비스이며, 팀원 제공 ZIP은 과제 템플릿이 아닌 완성 프로젝트다.

> 아래는 정답이 아니라 참고 예시다. 아이디어/문구/디자인/구성은 반드시 변경한다.

- [x] 서비스 기획서 (요약 예시) — 참고 형태 확인. Levelly 기획서는 멍냥케어의 아이디어·문구·구성을 그대로 복제하지 않는다.

    ```
    1. 서비스 개요
        - 서비스명: (예) “멍냥케어”
        - 타겟: 반려동물을 키우는 직장인
        - 목표: 간단한 소개 + AI 추천(입력 기반 안내) 제공
    2. 페이지/섹션 구성(예시)
        - 메인(Hero) / 서비스 소개 / AI 추천 / FAQ / 문의하기
    3. AI 기능 설계(예시)
        - 입력: 반려동물 종류/나이/기간
        - 출력: 추천 서비스 + 간단 안내 문구
        - 실패 처리: 빈 입력이면 “필수값을 입력하세요”, 오류면 “잠시 후 다시 시도하세요”
    ```
- [x] AI 기능 테스트 입력/결과 예시 (형태 예시) — 팀원 실제 200자 이상 영어 샘플 증빙, 이번 Chrome 빈 입력·정상 응답·오류·타임아웃 검사로 형태 확인.

    ```
    - 정상 입력: “고양이 / 2살 / 3일” → 추천 결과가 화면에 표시됨
    - 빈 입력: “(빈값)” → “필수값을 입력하세요” 안내가 표시됨
    - 긴 입력: 200자 이상의 설명 → 응답이 표시되거나, 지연 시 안내 문구가 표시됨
    ```
