# B2-1 요구사항 체크리스트

검증 기준일: 2026-10-07 (Asia/Seoul)

[과제문](과제문.md)과 첫 번째 원본 HTML의 모든 요구사항을 기준으로 작성했다. `[x]`는 실제 확인 완료, `[ ]`는 미충족 또는 확인 대기이다. 보너스는 선택 사항이며 필수 완료 기준과 구분한다. 원문 반복 항목도 해당 절에 각각 기록했다.

**현재 제출 상태: Git 조건과 최종 반영 확인이 남음.** 기본 기능과 이전 미션 프롬프트 등록은 검증을 통과했다. 팀원이 스크린샷 등을 완료했고 별도 실습이 필요 없다는 사용자 확인을 반영하여, 추가 개인 실습·학습자 설명 능력 확인·개인 계정의 재촬영을 이번 남은 작업에서 제외한다. 아래 미확인 표시는 직접 확인한 증거의 범위를 구분하기 위한 것으로, 개인 실습을 새로 요구하는 의미가 아니다. 현재 저장소의 커밋 10개·브랜치 병합·최신 업로드 조건은 그대로 관리한다.

실행 근거: [검증 로그](docs/evidence/검증_로그.md)의 실제 CLI 26개 시나리오와 빈 리스트 함수 4개. 실제 실행 파일은 `/opt/homebrew/opt/python@3.13/bin/python3.13`, 버전은 Python 3.13.1이다. 빈 전체 리스트는 코드 변경 없이 함수를 직접 호출한 검증이며, 실제 CLI 실행으로 가장하지 않았다.

## 1. 미션 소개의 검증 범위

프롬프트 카테고리·키워드·즐겨찾기 관리의 구현은 4절에서, 이전 미션 프롬프트 출처는 2·4·7절에서 확인한다. Git 학습·본인의 설명 능력을 프로그램 기능 완료와 혼동하지 않는다.
