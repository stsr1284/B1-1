# B3 작업 지침

작업 전 [과제문](과제문.md), [진행계획](진행계획.md)을 읽는다.
공통 규칙은 [코드 컨벤션](docs/CODE_CONVENTIONS.md), [아키텍처](docs/ARCHITECTURE.md), [파일 구조](docs/FILE_STRUCTURE.md), [협업 규칙](docs/COLLABORATION.md)에 따른다.

- 사용자의 최신 지시를 우선하고, 과제 원문을 임의 수정하지 않는다.
- B3-1이 기준 데이터를 생성하며 B3-2는 같은 정제본을 초기 적재한다.
- 계획과 실행 완료를 구분한다. 실제 결과를 확인한 항목만 완료로 기록한다.
- 데이터·실행 파일·제출 결과는 필요한 단계에 생성한다.

- 현재 주제는 2025년 따릉이·버스·지하철 이용량이며 기본 키는 (date, mode)다. 용어 설명 원문의 기온 예시는 과거 대화 기록이다.
