# 나만의 프롬프트 관리

이전 미션에서 작성한 프롬프트를 보관하고, Python 콘솔에서 추가·목록·카테고리 조회·검색·상세 보기·즐겨찾기로 관리하는 B2-1 과제 프로그램입니다. 리스트·딕셔너리와 함수로 구성하며 외부 라이브러리 설치가 필요 없습니다.

프로그램의 필수 기능과 이전 미션 기본 프롬프트 3개 등록을 확인했습니다. 현재 목록·추가·검색 실행 스크린샷도 갱신해 main에 병합·푸시했고, GitHub 원격 코드·이미지와 로컬 파일의 일치를 확인했습니다. 별도 개인 실습·계정 연동·본인 설명 능력은 기존 미검증 범위를 유지합니다. 과제 원문과 대조한 완료 기준·변경 이유·증명은 [요구사항 체크리스트](요구사항_체크리스트.md#원문에-따른-과제-설명변경완료-증명)에 정리했습니다.

## 실행 방법

Python **3.10 이상**이 필요합니다. 저장소 루트에서 실행합니다.

```bash
cd B2-1
python3 main.py
```

`python3 --version`이 3.10 미만이면 Python 3.10 이상을 지정하세요. 현재 환경에서는 `python3.13 main.py`로 검증했습니다. 메뉴 번호를 입력하고 Enter를 누릅니다.

## 기능

| 번호 | 기능 |
| --- | --- |
| 1 | 제목·내용·카테고리를 입력해 프롬프트 추가 |
| 2 | 전체 프롬프트의 번호·카테고리·제목·즐겨찾기 표시 |
| 3 | 카테고리별 조회 |
| 4 | 제목 또는 내용에 포함된 키워드 검색, 영문 대소문자 무시 |
| 5 | 번호로 선택한 프롬프트의 전체 내용 확인 |
| 6 | 번호로 선택한 프롬프트의 즐겨찾기 등록·해제 |
| 7 | 즐겨찾기 목록 조회 |
| 0 | 종료 |

빈 제목·내용·검색어는 다시 입력받습니다. 잘못된 메뉴·카테고리·프롬프트 번호에는 안내를 출력합니다. 검색·카테고리·즐겨찾기 결과에서도 전체 목록의 원래 번호를 유지합니다.

메뉴·카테고리·프롬프트 번호는 공통 검증 함수를 사용합니다. 앞뒤 공백과 앞자리 0을 허용하며, 문자·음수·범위 밖·매우 긴 숫자는 예외 없이 거절합니다. 상세 보기·즐겨찾기 관리에서 잘못된 번호는 다시 입력받고, `0`은 선택을 취소합니다.

추가 데이터와 즐겨찾기 변경은 **현재 실행 중에만 유지**합니다. 다시 실행하면 기본 데이터로 초기화합니다. JSON 저장·내보내기·수정/삭제·조회수/인기순 정렬은 선택 기능이며 구현하지 않았습니다.

## 추가 입력 기능

기본 화면의 문구를 유지하면서 다음 기능을 사용할 수 있습니다.

- 내용 입력에서 `/multi`를 입력하면 여러 줄 입력을 시작하고, `/end`로 완료합니다. 줄바꿈·빈 줄·들여쓰기를 보존합니다.
- 추가 중 제목·내용·여러 줄 입력·카테고리 선택에 `/cancel`을 입력하면 취소합니다. 미완성 항목은 등록하지 않습니다.
- 검색에서는 `/cancel`을 일반 검색어로 처리합니다.

## 코드 구조와 검증

- `main.py`: 기본 데이터, 공통 입력 검증, 메뉴 반복 및 기능 함수 18개.
- `과제문.md`: 원본 과제 본문과 요구사항.
- `요구사항_체크리스트.md`: 요구사항과 현재 확인 근거.
- `docs/evidence/검증_로그.md`: 실제 CLI 및 Git 검사 기록.

`main()`의 리스트를 각 기능에 전달합니다. 각 항목은 `title`, `content`, `category`, `favorite` 필드를 가진 딕셔너리이며 새 항목의 `favorite` 기본값은 `False`입니다. `numbered_prompts()`는 원래 번호를 부여하고 `find_prompts()`는 출력 없이 검색 결과를 반환합니다.

기본 데이터 적용 후 원본 프롬프트 3개의 본문 전체 비교와 현재 코드의 실제 CLI **26개 시나리오**, 빈 데이터·검색·숫자 경계의 직접 검사 **6개**가 통과했습니다. 목록·카테고리·제목/본문 검색·영문 대소문자 무시·검색 0건·상세 전문·즐겨찾기·추가·재시작 초기화를 확인했습니다. AST 비교로 기본 데이터 함수 외의 메뉴·입력·기능 코드가 그대로임을 확인했습니다. 이전의 CLI 18개 출력 일치와 C/U/I는 당시 버전의 기록이며, 기능 검증 근거는 검증 로그의 **원문 기준 완료 증명: 2026-10-07** 절이며, 최신 제출 반영 근거는 **실행 화면 및 main 반영 확인** 절입니다.
