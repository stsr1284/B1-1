## 출처·열

[서울시 행정동 단위 대중교통 출발지/도착지 승객수 정보 OA-21226](https://data.seoul.go.kr/dataList/OA-21226/F/1/datasetView.do). 공식 다운로드 파일을 그대로 저장했고 API 키를 사용하지 않았다.

`기준_날짜`, `시작_행정동_ID`, `종료_행정동_ID`, `승객_수_00`~`승객_수_23`의 **27열**이다. 모두 기본 분석에 필요하다.

[행정동 마스터 OA-21234](https://data.seoul.go.kr/dataList/OA-21234/S/1/datasetView.do) 원본 2,270행도 확보했다. 7자리와 8자리 ID를 임의 변환하지 않고 문자열 그대로 연결한다. 현재 시점 마스터이며 과거 행정동 경계·명칭을 보장하지 않는다.

## 해석·사용 기준

- 시간 기준 미확정을 이유로 탐색 자체를 막지 않는다. **“18시 시간대로 집계된 성수 지역행 이동량”**처럼 표현하며 “18시 도착 인원”이라고 단정하지 않는다.
- 2023~2025 장기 추세와 전년 동기간·요일·시간대 비교에 사용한다. 2026년은 이전 연도의 같은 기간으로 비교하며 최신 부분 월은 별도로 표시한다.
- 같은 관측 날짜·시간대·공통 지역 코드 범위를 맞춘다. 누락 날짜와 빈 시간대 셀을 0으로 채우지 않는다. 시간대만으로 관광객 수·이동 목적을 확정하지 않는다.
- 지역별 유입·유출은 관측된 OD의 도착·출발 지역 기준이다. 같은 동 안 이동은 별도 분리하고 승하차 집계와 더하지 않는다.
- 27개 열 이름·배열은 비교 가능하지만 연도별 수집·집계 방식이 완전히 동일하다는 뜻은 아니다. 역사적 코드 변경과 결측 패턴을 분석 단계에서 확인한다.

## 실제 검증과 남은 검사

- 모든 ZIP CSV를 끝까지 읽어 CRC를 확인하고 SHA-256, 모든 행의 날짜, 열 배열, 빈 파일, 행정동 ID 결측을 기록했다. 압축 해제 사본을 디스크에 생성하지 않았다.
- 2023-06 일부 CSV 첫 열 이름에 불필요한 `?"`가 있다. 이를 기록하고 읽을 때만 해당 열을 `기준_날짜`로 대응했다. 원본 바이트는 수정하지 않았다.
- 출발/도착 ID가 빈 행은 원본에 보존했다. 지역명에 연결되지 않는 ID도 제외·추정하지 않고 아래 검증 기록에 남겼다.
- 확보 단계에서는 숫자 셀·OD 중복·지역 관측 여부의 전수 검사를 수행하지 않았다. 이후 별도 분석 파이프라인에서 수행한 결과는 위 최종 리포트를 따른다. 실제 역사적 경계 불변은 여전히 확정하지 않았다.

- 여러 원본 CSV에 중복으로 등장한 관측 날짜: 0개.
