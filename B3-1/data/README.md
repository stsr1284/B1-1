# 현재 OD 분석 데이터

현재 분석에 사용하는 원본 72개, 가공본, 출처·검증 기록만 관리한다. 원본 내용은 변경하지 않았다.

```text
data/
├── raw/
│   ├── transit_hourly_od/{2023,2024,2025,2026}/  66 ZIP
│   ├── locations/admin/                         코드표 ZIP·마스터 CSV 2개
│   └── calendar/calendar_data_2023~2026.html     공휴일 자료 4개
├── processed/transit_od/
│   ├── months/                                 가공 집계 66 Parquet
│   └── *.csv                                   비교·품질·참조표 15개
├── metadata/
│   ├── transit_hourly_od/                      OD 수집·출처·검증 기록
│   ├── reference_sources.json                  현재 참조 원본의 수집 기록
│   ├── catalog.json                            현재 원본 72개 목록·해시
│   └── cleanup_20261027.json                    미사용 자료 이동 기록
├── README.md
└── TRANSIT_OD.md
```

| 구분 | 자료 | 용도 |
|---|---|---|
| 원본 | 2023-01~2026-10-21 시간대별 대중교통 행정동 OD, 66 ZIP | 지역 간·요일·시간대 이동 변화 |
| 참조 원본 | 대중교통 행정동 마스터, 월별 행정동 코드표 | ID와 지역명 연결·지역 비교 기준 검증 |
| 참조 원본 | 2023~2026 공식 달력 데이터 HTML 4개 | 공휴일 분리; 후속 공지는 검증 기록에 명시 |
| 가공본 | 지역·날짜·시간 집계와 비교·품질표 | 리포트와 그래프에 사용; 새로운 관측으로 합산하지 않음 |
| 관리 기록 | 출처·해시·수집 및 검증 기록 | 재현과 원본 보존 확인 |

현재 원본 약 **5.894GB**, 가공본 약 **108.6MB**다. 주 분석은 서울 398개 동 사이 이동, 보조 분석은 해당 목적지로 들어오는 비어 있지 않은 전체 출발 ID(서울 밖·동 내부 포함)다. 둘을 더하지 않는다.

미사용 승하차·역/정류장 위치 자료와 이전 가공본·기록, 달력 안내 페이지는 [tmp/2026-10-27/unused_data/](../tmp/2026-10-27/unused_data/)로 이동했다. 삭제가 아니므로 디스크 여유 공간은 늘어나지 않는다. 현재 분석에서는 해당 폴더를 읽지 않는다.
