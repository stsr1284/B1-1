# 이번 OD 분석 데이터 사전

| 위치 / 열 | 뜻 | 사용·처리 |
|---|---|---|
| raw/transit_hourly_od/*.zip | 공식 다운로드 원본 | 불변, 월 ZIP 안 일 CSV; 2026-10은 일 ZIP |
| 기준_날짜 | 원본 기준 날짜 | 실제 레코드 날짜 검사; 파일 이름만으로 관측일 판단하지 않음 |
| 시작_행정동_ID / 종료_행정동_ID | 출발 / 도착 행정동 코드 | 문자열, 공식 마스터만 연결 |
| 승객_수_00~23 | 원본 시간대별 이동량 | 음이 아닌 정수 또는 빈 셀; 빈 셀은 미상 |
| region_crosswalk.csv | raw_id→시도\|구\|동 / 안정 이름 여부 | 7/8자리의 공식 명시 별칭만 연결 |
| seoul_monthly_codes.csv | 월별 서울 행정동 코드·이름 | 과거 이름·코드 변화 점검; 교통 OD 코드와 직접 숫자 조인 금지 |
| months/*.parquet / h00~h23 | 지역·일·범위별 알려진 이동량 합 | 전부 빈 시간은 null |
| months/*.parquet / n00~n23 | 합에 기여한 숫자 셀 수 | 고유 인원이나 조사 표본 크기가 아님 |
| scope=internal_in / internal_out | 고정 서울 지역 간 유입 / 유출 | 동일 동 내부 제외, 서로 합산 금지 |
| scope=all_origins_including_within | 비어 있지 않은 출발 ID 전체→관심 서울 동 | 서울 외·동 내부 포함. 코드 미연결 출발지도 포함될 수 있음 |
| calendar.csv | 날짜·요일·공휴일·특별일 | 일반 주말/평일과 분리 |
| outputs/od_validation/*.json | 원본/가공 SHA, 결측·중복·코드·검산 | 분석 결과와 별도 관리 |

단위는 공개 자료에 기록된 이동량(건)이다. 고유 방문자 수·관광객 수·연결된 개인의 이동시간이나 체류시간이 아니다. 알려진 셀의 합은 미상 셀을 복원한 전체 이동량이 아니다.
